L'alternativa nativa a Spotify.
Più veloce, più pura.

Lyra è un client desktop minimale compilato per Windows, macOS e Linux. Sostituisce l'app ufficiale basata su Chromium con un binario da soli 20 MB di RAM e audio WASAPI Bit-Perfect.

Download per Windows (x64)
winget install cristianobleve.lyra
EFFICIENZA RADICALE

20 MB di memoria. Zero Electron.

Mentre l'applicazione ufficiale carica 6 processi Chromium separati consumando oltre 1.2 GB di RAM, Lyra gira in un singolo processo nativo a 64-bit con un tempo di avvio a freddo inferiore a 150 millisecondi.

FEDELTÀ ACUSTICA

Audio WASAPI Bit-Perfect a 320 kbps.

Su Windows, Lyra si interfaccia con i driver WASAPI a basso livello per inviare i campioni Vorbis decodificati direttamente al tuo DAC audio, senza passare dai ricampionamenti forzati del mixer di sistema.

PRIVACY & SICUREZZA

Zero telemetria. Nessun server proprietario.

I tuoi token di sessione (OAuth 2.0 PKCE) e la configurazione risiedono solo sul tuo disco locale in config.json. Nessuna informazione o metadato viene inviato a server intermedi.

CONFIGURAZIONE

Setup in 3 passaggi

In conformità alle policy Spotify per sviluppatori di Febbraio 2026, ogni utente open-source registra il proprio Client ID personale e sicuro.

01

Crea un'app nella dashboard Spotify

Accedi alla Spotify Developer Dashboard ↗ e clicca su "Create App".

02

Inserisci il Redirect URI

Nelle impostazioni dell'app, incolla questo URI e abilita le Web API:

http://127.0.0.1:8888/callback
03

Incolla il Client ID in Lyra

Copia il tuo Client ID univoco e incollalo nella schermata iniziale di Lyra. Pronto!
